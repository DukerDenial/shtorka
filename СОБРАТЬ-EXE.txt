Как получить .exe без установки Rust (сборка на серверах GitHub, бесплатно):

1. Зайдите на github.com (создайте аккаунт, если нет) -> New repository -> имя shtorka -> Create.
2. На странице репозитория нажмите "uploading an existing file" и перетащите ВСЮ распакованную папку
   (важно: вместе со скрытой папкой .github). Нажмите Commit changes.
3. Вкладка Actions -> "Сборка Шторки (Windows)" -> Run workflow. Ждать 10-15 минут.
4. Откройте завершённый запуск -> внизу Artifacts -> Shtorka-Windows. Внутри установщик *-setup.exe и shtorka.exe.
Если сборка упала (красный крестик) - откройте её, скопируйте текст ошибки и пришлите мне.
