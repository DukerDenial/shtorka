# Шторка

Тонкая полоска (~0,5 см) сверху экрана. Наведите мышь или кликните — она плавно раскрывается в шторку. Кнопка со стрелками растягивает шторку на всю ширину экрана.

## Что внутри

| Вкладка | Что делает |
|---|---|
| Управление | Как в Hitodama: громкость и mute, плеер (то, что сейчас играет в Windows: обложка, трек, пауза/дальше/назад), Wi-Fi, Bluetooth, ночной режим с ползунком силы, светлая/тёмная тема Windows. Правый клик по Wi-Fi/Bluetooth открывает их настройки Windows |
| Gemini | Свой чат с Gemini в шторке, ответы приходят потоком. Кнопка «Открыть Gemini в браузере» открывает обычный сайт |
| Задачи | Список дел со сроком, просроченные подсвечиваются, число невыполненных — на вкладке |
| Нагрузка | Процессор с графиком, память, сеть, диски, топ-5 процессов по процессору и по памяти |
| Обои | 8 встроенных обоев (нарисованы специально, лицензия не нужна) или «Моя папка». Клик по центральной карточке — обои сменились, «Случайные» |
| Приложения | Плитки программ и ярлыков (exe, lnk, bat, url), правый клик — убрать |
| Питание | Заблокировать, выйти, перезагрузить, выключить (последние три — с подтверждением) |

Управление: наведите мышь — раскроется; ушла мышь — свернётся; кнопка с булавкой не даёт сворачиваться; `Esc` сворачивает.

## Запуск на Windows 10/11

Нужно один раз поставить:

1. **Node.js** (LTS) — https://nodejs.org
2. **Rust** — https://rustup.rs
3. **Microsoft C++ Build Tools** (в установщике отметьте «Разработка классических приложений на C++») — https://visualstudio.microsoft.com/visual-cpp-build-tools/
4. **WebView2** — в Windows 11 уже есть, для Windows 10 https://developer.microsoft.com/microsoft-edge/webview2/

Дальше в папке проекта:

```
npm install
npm run dev        # запуск для проверки
npm run build      # установщик: src-tauri/target/release/bundle/nsis/
```

Первая сборка идёт 5–15 минут: Rust собирает все зависимости.

## Gemini: ключ, а не подписка

Чат работает через Gemini API. Платная подписка Gemini (Google AI Pro и т.п.) и API — разные продукты, подписка ключ не даёт.

1. Откройте https://aistudio.google.com/apikey и создайте ключ.
2. В шторке: вкладка Gemini → «Ключ и модель» → вставьте ключ → «Сохранить».

Ключ лежит только на вашем компьютере (в хранилище приложения) и уходит только в Google.

Нюансы:
- Есть бесплатный тариф с лимитами. В ЕЭЗ, Великобритании и Швейцарии Google разрешает приложениям только платный режим: включите оплату в AI Studio.
- Gemini API доступен не во всех странах: https://ai.google.dev/gemini-api/docs/available-regions
- Модель по умолчанию — `gemini-flash-latest` (всегда свежая «быстрая»). Если хотите другую, впишите её имя в поле «Модель».
- Если не хотите возиться с ключом, кнопка «Открыть Gemini в браузере» открывает обычный сайт с вашей подпиской.

## Шрифты

Как на сайте Hitodama: Figtree (интерфейс), EB Garamond (часы и крупные заголовки), JetBrains Mono (мелкие подписи). У Figtree нет кириллицы — русские буквы рисует близкий Onest. Все четыре — SIL Open Font License 1.1, лежат в `src/fonts/`. Авторы: Erik Kennedy (Figtree), Georg Duffner и Octavio Pardo (EB Garamond), JetBrains (JetBrains Mono), Onest — Sergey Kachanov.

Светлая/тёмная тема самой шторки следует теме Windows; плитка в «Управлении» переключает тему Windows.

## Устройство проекта

```
src/                фронтенд без сборки: index.html, style.css, app.js
src-tauri/src/
  lib.rs            окно, обои, запуск программ, питание, команды
  controls.rs       громкость, Wi-Fi/Bluetooth, плеер, тема, ночной режим (Windows API)
  night.rs          расчёт цвета ночного режима
  stats.rs          сбор нагрузки (sysinfo)
src-tauri/tauri.conf.json   окно: без рамки, прозрачное, поверх всех, без значка в панели задач
```

## Известные ограничения

- Часть «Управления» (громкость, плеер, радио, ночной режим) использует системные API Windows и в моей среде не запускалась — возможны шероховатости на разных ПК.
- Ночной режим меняет гамму основного монитора; некоторые драйверы/видеокарты это игнорируют. При выходе из программы цвета возвращаются.
- Wi-Fi/Bluetooth переключаются, только если Windows разрешает приложениям управлять радио (Параметры → Конфиденциальность → Радио).

- Шторка не показывается поверх игр и видео в настоящем полноэкранном режиме (оконный без рамок — показывается).
- Несколько мониторов: шторка остаётся на том, где запустилась.
- У плиток приложений буква вместо настоящего значка.
- Нет автозапуска с Windows — можно положить ярлык собранного приложения в `shell:startup`.
- Сроки задач только подсвечиваются, уведомлений нет.
- Температуры в «Нагрузке» нет: Windows не отдаёт её без драйверов.
