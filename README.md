# Шторка

**Тонкий язычок сверху экрана, который раскрывается в центр управления Windows.**
Громкость, плеер, Wi-Fi и Bluetooth, ночной режим, тема, чат с Gemini, задачи, нагрузка ПК, обои и ярлыки — в одном месте.

## Как это выглядит и работает

В покое на экране виден только крошечный тёмный язычок (72×8 px) по центру верхнего края. Наведите на него мышь или кликните, и он плавно раскрывается в шторку. Уберите мышь, и шторка сворачивается. Кнопка со стрелками растягивает её на всю ширину экрана, булавка не даёт сворачиваться, `Esc` сворачивает сразу.

## Возможности

| Вкладка | Что внутри |
|---|---|
| **Управление** | Громкость и «без звука», плеер (обложка, трек, пауза / далее / назад для всего, что играет в Windows), Wi-Fi, Bluetooth, ночной режим с регулировкой силы, светлая и тёмная тема Windows |
| **Gemini** | Свой чат с Gemini прямо в шторке (ответы приходят потоком). Рядом кнопка «Открыть Gemini в браузере» для обычного сайта |
| **Задачи** | Список дел в стиле iOS «Напоминания»: сроки, просроченные подсвечиваются, счётчик на вкладке |
| **Нагрузка** | Процессор и память кольцами, графики за минуту, сеть, диски, процессы по CPU и RAM |
| **Обои** | 23 встроенных обоев в альбомах (Пейзажи, Море, Космос, Геометрия, Текстуры, Цвета) или любая ваша папка. Клик по центральной карточке ставит обои |
| **Приложения** | Плитки программ и ярлыков (`exe`, `lnk`, `bat`, `url`), правый клик убирает плитку |
| **Питание** | Заблокировать, выйти, перезагрузить, выключить (последние три с подтверждением) |

Шторка следует теме Windows (светлая или тёмная), а плитка в «Управлении» эту тему переключает.

## Скачать готовый .exe

Сборка идёт автоматически на серверах GitHub:

1. Откройте вкладку **Actions** этого репозитория и выберите последний зелёный запуск.
2. Внизу, в блоке **Artifacts**, скачайте `Shtorka-Windows`.
3. Внутри установщик `Shtorka_…_x64-setup.exe` (ставится без прав администратора, сам подтянет WebView2) и одиночный `shtorka.exe`, который запускается без установки.

Если Windows покажет «SmartScreen защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Приложение не подписано сертификатом разработчика.

Запустить сборку вручную можно кнопкой **Run workflow** на вкладке Actions.

## Gemini: ключ, а не подписка

Чат работает через Gemini API. Платная подписка Gemini (Google AI Pro и т.п.) и API это разные продукты, подписка ключ не даёт.

1. Откройте <https://aistudio.google.com/apikey> и создайте ключ.
2. В шторке: вкладка Gemini → «Ключ и модель» → вставьте ключ → «Сохранить».

Ключ хранится только на вашем компьютере и уходит только в Google.

- У Google есть бесплатный тариф с лимитами. В ЕЭЗ, Великобритании и Швейцарии бесплатный режим для приложений недоступен, нужно включить оплату в AI Studio.
- Gemini API доступен не во всех странах: <https://ai.google.dev/gemini-api/docs/available-regions>
- Модель по умолчанию `gemini-flash-latest`, её можно поменять в настройках чата.

## Сборка из исходников

Нужно один раз поставить:

1. [Node.js](https://nodejs.org) (LTS)
2. [Rust](https://rustup.rs)
3. [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (отметьте «Разработка классических приложений на C++»)
4. WebView2 (в Windows 11 уже есть)

```bash
npm install
npm run dev      # запуск для проверки
npm run build    # установщик: src-tauri/target/release/bundle/nsis/
```

Если `npm install` ругается на сертификат (корпоративная сеть), выполните `set NODE_OPTIONS=--use-system-ca` и повторите.


## Известные ограничения

- Громкость, плеер, радио, ночной режим и смена темы используют системные API Windows; на разных ПК и драйверах возможны шероховатости.
- Ночной режим сначала пробует настоящую цветовую коррекцию экрана; если драйвер её не принимает, включается тёплая плёнка поверх основного монитора.
- Wi-Fi и Bluetooth переключаются, только если Windows разрешает приложениям управлять радио (Параметры → Конфиденциальность → Радио).
- Шторка не показывается поверх игр и видео в настоящем полноэкранном режиме.
- Несколько мониторов: шторка остаётся на том, где запустилась.
- У плиток приложений буква вместо настоящего значка.
- Нет автозапуска с Windows: положите ярлык приложения в `shell:startup`.
- Температуры в «Нагрузке» нет: Windows не отдаёт её без драйверов.
